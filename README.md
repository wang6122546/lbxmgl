# 施工安全管理前端原型

基于 2026-10-15 有权限访问的测试环境 UI 采集，以原生 HTML / CSS / ES Modules 复刻。包含 19 个独立页面，所有业务记录为虚构演示数据。

## 外网访问

- 原型地址：https://wang6122546.github.io/lbxmgl/
- 源码仓库：https://github.com/wang6122546/lbxmgl
- GitHub Pages 从 `main` 分支根目录发布，推送后自动更新。
- 数据仅保存在当前浏览器中，不会同步到其他访客或本地预览站点。

## 启动

在本目录运行：

```sh
python3 -m http.server 8770 --bind 127.0.0.1
```

访问 http://127.0.0.1:8770/ 。请通过 HTTP 打开，不要使用 file://。

无需安装依赖、无需联网、没有 CDN 或原系统 API 调用。IndexedDB 保存业务数据，BroadcastChannel 通知其他本地标签页刷新。浏览器清理站点数据会删除演示修改。

## 页面与能力

- 六个主菜单：施工项目管理、施工现场、风险库、参数配置、施工项目报表、监管责任清单。
- 项目详情拆为独立入口：项目信息、相关方企业、人员、证书、培训、风险点和排查计划。
- 项目、现场、风险库、风险点、类型、企业、人员、证书、日报表及报表基础字典支持本地增删改或详情。
- 筛选、重置、分页、CSV 导出、表单必填、起止日期校验、关联引用保护、演示审核/退场/延期和配置保存。
- 项目成员、企业、风险点数量从同一 Repository 计算；类型和字典重命名同步引用。
- 左下角“重置演示数据”恢复初始状态。

## 已知边界

这是可运行的前端交互原型，未连接后端。原系统的所有深层弹窗与权限组合未穷尽采集，不能视为完整业务系统或像素级验收完成。

- 真实审批流程与权限、资质校验、黑名单、短信、定时任务、真实文件上传下载未接入。
- 批量导入模板、人员跨项目选择、组织人员选择和相关方履历细节待确认；按钮会明确解释状态。
- 进场管理已恢复原系统右侧抽屉及嵌套抽屉，独立 HTML 入口打开时也以列表为背景还原抽屉状态。
- 日报表、现场、人员表单已补采并修正结构；未穷举的业务规则与控件差异见 reference/FIDELITY_AUDIT.md。
- 附件只记录文件名，不持久化文件内容；演示样例文件没有真实文件。
- 所有演示账号共享相同数据，“我负责的 / 全部项目”呈现同一演示集合；真实账号权限待接入。
- 培训、排查计划保留已观察字段及空状态，不自动伪造任务。
- 采用桌面布局；移动端未作为验收目标。

完整页面清单见 PROJECT_MAP.md；来源与采集范围见 reference/TRAVERSAL.md；验证结果见 tests/ACCEPTANCE.md。
